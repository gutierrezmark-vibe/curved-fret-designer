# Curved Fret Designer

A browser-based luthier tool for designing **exponential, divergent, convergent and "S"-curve fretboards**: instruments where every string has its own scale length and the frets bend into smooth curves instead of straight or fanned lines.

- Exponential scale progressions (`L[n] = L[n-1] ± scalar · growth^(n-1)`), with linear fan as the special case `growth = 1`
- Divergent (D-scale), convergent (C-scale) and S-curve frets, where divergent and convergent halves meet in the middle
- Any number of strings; board widths grow to fit
- A photo-realistic 3D preview of the board, curved fret wire and strings
- 1:1 templates and fret tables for building

Everything runs in the browser. No install, no server.
